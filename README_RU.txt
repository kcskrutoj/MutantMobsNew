MutantMobs для Minecraft Java 1.16.5 / Forge

Сборка через GitHub Actions:
1. Создай репозиторий на GitHub.
2. Загрузи ВСЕ файлы и папки из этого архива в корень репозитория.
3. Открой вкладку Actions.
4. Выбери "Build MutantMobs mod" и нажми Run workflow.
5. После успешной сборки открой запуск и скачай artifact "MutantMobs-1.16.5".
6. Внутри artifact будет .jar для папки mods.

Требуется Minecraft Forge 1.16.5.
